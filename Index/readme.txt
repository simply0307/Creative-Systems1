ARCHIVE PURPOSE

This archive is the foundational creative library for EGGS / Para gaming projects.

It should be treated as:

* a source of recurring faction logic
* a source of player identity systems
* a source of achievement/card/profile inspiration
* a source of thematic critique
* a source of mechanics, aesthetics, and competitive archetypes
* a long-term canon and design reference

It should not be treated as:

* one finished story
* one game’s lore bible only
* a generic fantasy wiki
* a requirement that every project literally include every faction
* a pile of random notes to summarize and forget

Every EGGS game should draw inspiration from this library in some way, but the expression can be direct, indirect, mechanical, aesthetic, symbolic, or hidden.
